# Faerûn Cartographers

Map skills by Murray Fife.

## Included skill

- **fantasy-cartography-core**: Shared rules for source-map positions, scale, and geometry.

## Install

Add this repository as a plugin marketplace in a supported client. For Codex CLI:

```sh
codex plugin marketplace add https://github.com/blindsquirrelpublishing/faerun-cartographers.git
```

Then select Faerûn Cartographers from that marketplace.

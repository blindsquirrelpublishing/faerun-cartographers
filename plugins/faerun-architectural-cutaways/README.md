# Faerûn Architectural Cutaways

One reusable skill: `fantasy-architectural-cutaway-map`. Build 3D orthographic or isometric cutaways that keep surface geometry aligned with the approved map while showing known underground structures and marking uncertain details.

Inspired by the Dragonspear Castle above-ground/underground cutaway: outer and inner wards, keep, basement, Avernus portal cave, Warrens, buried labyrinth and Nepenthe River.

## Install

**Claude Code**
```text
/plugin marketplace add blindsquirrelpublishing/faerun-cartographers
/plugin marketplace update faerun-cartographers
/plugin install faerun-architectural-cutaways@faerun-cartographers
```

**Codex**
```sh
codex plugin marketplace add https://github.com/blindsquirrelpublishing/faerun-cartographers.git
codex plugin marketplace upgrade faerun-cartographers
codex plugin add faerun-architectural-cutaways@faerun-cartographers
```

Choose the `fantasy-architectural-cutaway-map` skill in the installed plugin. Exact UI and commands depend on your client version.

This skill is not a measured excavation survey. It requires approved above-ground geometry and documented level connections; missing chamber geometry is interpretive.

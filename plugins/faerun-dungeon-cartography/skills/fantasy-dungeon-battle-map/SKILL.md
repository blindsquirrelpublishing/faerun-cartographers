# Fantasy Dungeon Battle Map

Read ../../references/dungeon-geometry-master.md. Require an approved master and an explicit battle grid size, normally 5 ft per square only when dimensions are known or approved as game design assumptions.

Render top-down orthographic walls, doors, passages, elevation marks, stairs, water, hazards, props and optional lighting. Keep room footprints, connections and feature ids fixed. Use true square cells, with clear playable floor and unobscured doors. If the source has no dimensions, offer an explicitly proposed playable-scale adaptation, never pass it off as source-accurate. Export GM labeled and player unlabeled variants when requested. Validate every entrance and connection against the master; flag all invented furniture, encounters and traps as optional additions.

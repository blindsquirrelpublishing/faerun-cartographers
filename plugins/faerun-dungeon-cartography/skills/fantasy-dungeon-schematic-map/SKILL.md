# Fantasy Dungeon Schematic Map

Read ../../references/dungeon-geometry-master.md and create or load the approved Dungeon Geometry Master first.

Produce a true orthographic top-down cave and dungeon plan with black ink walls, clear room outlines, passages, bridges, stairs, pits, water and keyed points of interest. Use restrained parchment or blueprint styling. Preserve original room ids, names, adjacency and topology. Distinguish passage crossings from actual connections. Put long labels in a keyed legend, not over geometry. Use a square reference grid only if the scale is established; otherwise mark NOT TO SCALE. Where appropriate apply Faerûn Cartographers plat v1.8 framing without changing geometry. Output a source-to-map check of rooms, edges and uncertain features.

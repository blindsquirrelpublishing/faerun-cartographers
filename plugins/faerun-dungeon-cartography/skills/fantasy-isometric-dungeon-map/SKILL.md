# Fantasy Isometric Dungeon Map

Read ../../references/dungeon-geometry-master.md. Build from the approved master, not a previously generated scenic image. Use a fixed isometric camera and consistent projection. Show rock cutaways, walls, stairs, shafts, waterfalls, pools and atmospheric lighting. Preserve x/y positions and all source connections. Use only known z values; mark speculative elevations and geometry visibly as conceptual. Expose hidden passages using cutaway sections, transparent layers or separate floor panels, never by relocating rooms. Place labels as keyed callouts with room ids. Do not invent staircases, bridges, doorways or tunnels for visual appeal. Validate projected layout against the 2D master and report hidden/uncertain elements.
